# 퀴즈 생성 one-shot 예시

## 입력
주제: 운영체제의 프로세스 스케줄링
난이도: 보통
지식수준: 학사

## 출력 형식 예시
```json
{
  "quizTitle": "프로세스 스케줄링 기초",
  "questions": [
    {
      "questionText": "선점형 스케줄링(Preemptive Scheduling)의 특징으로 옳은 것은?",
      "options": [
        "실행 중인 프로세스는 자발적으로 CPU를 양보할 때까지 계속 실행된다",
        "운영체제가 실행 중인 프로세스를 강제로 CPU에서 제거할 수 있다",
        "모든 프로세스는 동일한 시간 동안 CPU를 사용한다",
        "프로세스 우선순위는 변경될 수 없다"
      ],
      "correctIndex": 1,
      "explanation": "선점형 스케줄링에서는 운영체제가 더 높은 우선순위 프로세스를 위해 현재 실행 중인 프로세스를 강제로 중단시킬 수 있습니다."
    }
  ]
}
```
