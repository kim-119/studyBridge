# 프론트엔드 인수인계서 - AI 에이전트 피드백 기능 연동

## 1. 문서 목적
FastAPI에 AI 답변 피드백/의견 생성 로직이 추가되었으며, 프론트가 피드백 대상 답변 또는 질문을 전달할 수 있어야 함을 설명한다.

## 2. 필요한 UI 기능
- 각 AI 답변 옆에 “피드백 요청” 버튼
- 각 AI 답변 옆에 “다른 AI 의견 듣기” 버튼
- 멀티 에이전트 답변 비교 버튼
- 피드백 대상 답변 선택 기능
- 피드백을 수행할 에이전트 선택 기능
- need_target 응답이 오면 피드백 대상 답변 선택 안내 표시

## 3. 프론트에서 전달해야 할 값
- message
- target_answer
- target_question
- previous_answers 또는 previousAnswers
- agent_id 또는 reviewer_agent_id
- source_agent_id
- feedback_mode

## 4. 권장 요청 예시
{
  "agent_id": 2,
  "message": "이 답변에 의견 달아줘",
  "target_question": "Java OOP가 뭐야?",
  "target_answer": "Java OOP는 클래스와 객체를 중심으로...",
  "feedback_mode": "answer_review"
}

## 5. 화면 처리
- 피드백 결과는 일반 AI 답변과 구분해서 표시
- “피드백 결과” 또는 “다른 AI 의견” 라벨 표시
- need_target 응답이 오면 사용자에게 피드백 대상 답변을 선택하라고 안내
- 멀티 에이전트 비교 결과는 답변별 장단점 카드로 표시 가능
- 프론트는 OpenAI API Key를 직접 다루지 않아야 함
- 기존 answer 필드는 그대로 화면 본문으로 렌더링 가능

## 6. 체크리스트
- [ ] 답변별 피드백 버튼 존재 여부
- [ ] target_answer 전달 여부
- [ ] target_question 전달 여부
- [ ] reviewer agent 선택 가능 여부
- [ ] previous_answers 전달 여부
- [ ] need_target 응답 처리 여부
- [ ] feedback_type 라벨 표시 여부
- [ ] OpenAI API Key 미노출 여부
